# Production agents: one video per agent (Analyze Mode)

In Analyze Mode, both Recreate and Create, each video is produced by its **own background agent**,
so no video waits behind another's Higgsfield job. The work is split:
- **this session** analyses, decides and plans (command A1–A9; skills `atp-analyze-*`, `atp-asset-plan`, `atp-analyze-produce`, and per video `atp-plan-video`, `atp-write-request`, `atp-precheck`);
- **each agent** runs its one video from inputs to CapCut project (X3–X10; skills `atp-inputs`, `atp-submit`, `atp-postprocess`, `atp-qc`, `atp-record`, invoked from its contract).

At most `config.json → production.max_parallel_agents` (5) agents run at once. Edit Mode never uses
production agents.
